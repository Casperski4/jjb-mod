# Stands & Bankai (Fabric 1.20.1)

Кооперативный мод: стенды и банкаи, 4 региона-арены, общий сюжет на ~4 часа с диалогами героев.
Все персонажи оригинальные.

## Сборка

Нужны JDK 17+ и Gradle (или `gradle wrapper` один раз).

    gradle build

Готовый файл: `build/libs/jojobleach-0.1.0.jar`. Кладётся в `mods/` вместе с Fabric API 0.92.2+1.20.1
(на сервер и на каждый клиент).

ВАЖНО: проект написан без пробной компиляции (в среде разработки не было доступа к Fabric Maven).
Возможны мелкие ошибки имён API под yarn 1.20.1. Пришли текст ошибки, исправлю.

## Мультиплеер

- Сюжет общий на сервер. `/jjb story start` может запустить любой игрок.
- Реплики героев видят все, идут по очереди с паузой ~3.5 сек.
- Убийства любого игрока идут в общий счётчик.
- Цели, HP боссов и размер волн растут с числом игроков (см. `Balance.java`).
- Главы «дойти до маяка» засчитываются, когда у маяка ВСЕ игроки онлайн.
- Зашедший позже получает пропущенные награды и телепортируется к группе.
- После смерти игрок возрождается в регионе текущей главы.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/jjb story start` | все | запустить сюжет для группы |
| `/jjb story status` | все | текущая глава и цель |
| `/jjb story retry` | все | перезапустить главу (босс пропал, застряли) |
| `/jjb story skip` | оператор | пропустить главу |
| `/jjb story reset` | оператор | сбросить сюжет |
| `/jjb spirit` | все | показать Дух |
| `/jjb give <id>` | оператор | выдать стенд или клинок |
| `/jjb map` | оператор | перестроить 4 региона |

## Управление

- ПКМ предметом: стенд или шикай. Shift+ПКМ клинком: банкай (с главы 9).
- Способности тратят Дух (макс. 100, +2 в секунду), у каждой своя перезарядка.
